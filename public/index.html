Thay Đổi Logo Góc Trái Ứng Dụng

Bạn có thể thay đổi logo hiển thị ở góc trên bên trái màn hình bằng một trong 2 cách:

CÁCH 1: TẢI ẢNH TRỰC TIẾP TỪ TRÌNH DUYỆT
Bấm để chọn file logo hoặc kéo thả ảnh vào đây
Hỗ trợ .png, .jpg, .svg, .webp (Khuyên dùng ảnh nền trong suốt)
CÁCH 2: THẢ VÀO THƯ MỤC MÁY TÍNH
Copy file ảnh của bạn vào thư mục:
public\custom-logo\logo.png
Sau khi copy xong, chỉ cần tải lại trang là logo sẽ tự động cập nhật!
Cài Đặt Hệ Thống & Dữ Liệu
📂 Nơi Lưu Dữ Liệu Của Bạn:
Tất cả dữ liệu được lưu an toàn tại máy của bạn:
• File dữ liệu: data\db.json
• File đính kèm: uploads\tasks\
• Logo tùy biến: public\custom-logo\
