HƯỚNG DẪN THAY ĐỔI LOGO ỨNG DỤNG
==================================================

Bạn có thể thay đổi logo hiển thị ở góc trên bên trái của trang web theo 2 cách cực kỳ đơn giản:

CÁCH 1: THẢ TRỰC TIẾP VÀO THƯ MỤC NÀY (WINDOWS EXPLORER)
--------------------------------------------------
1. Chuẩn bị file logo của bạn (hỗ trợ định dạng .png, .jpg, .svg, .webp).
2. Đổi tên file logo đó thành:
   logo.png (hoặc logo.jpg, logo.svg, logo.webp)
3. Dán (paste) file đó trực tiếp vào thư mục này:
   d:\Web khoa học các nhân hóa\public\custom-logo\
4. Tải lại trang web (hoặc F5), hệ thống sẽ tự động hiển thị logo mới của bạn!

CÁCH 2: BẤM NÚT ĐỔI LOGO TRÊN GIAO DIỆN WEB
--------------------------------------------------
1. Mở trang web LifeOS.
2. Bấm vào biểu tượng Cài đặt / Đổi Logo ở góc trên bên phải thanh điều hướng.
3. Chọn ảnh từ máy tính của bạn và bấm Xác nhận.
4. Hệ thống sẽ tự động lưu và hiển thị logo mới ngay lập tức.
